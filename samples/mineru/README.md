# MinerU Response Samples

This directory is reserved for live MinerU precise parsing response captures.

The plugin currently implements the documented v4 signed-upload flow, but a
real MinerU Token was not available during implementation. Before production
use, run one small PDF through the settings panel/workflow and save redacted
samples here:

- `file-urls-batch.response.json`
- `extract-results-batch.running.json`
- `extract-results-batch.done.json`
- `zip-file-list.json`
- `content-list-v2.sample.json`
- `content-list.sample.json`
- `middle.sample.json`

Do not commit API tokens, signed upload URLs, private paper text, or personal
account identifiers.
